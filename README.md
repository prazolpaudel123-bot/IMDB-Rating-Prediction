# IMDB-Rating-Prediction
Predicts IMDb ratings (1–10) from movie and TV plot descriptions using a SimpleRNN model. Includes a Streamlit web app where you can paste a plot and get a predicted rating, with sample plots to try.
Source: https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews. 
Download all (.py, .ipynb, .pkl, .h5) files in a folder In imdb_rating_prediction.py file, go to terminal and run streamlit To run streamlit, go to terminal of the .py file and enter py -m streamlit run "file_location\imdb_rating_prediction.py" 
For example, in my device I enter: py -m streamlit run "L:\Softwares\VS Code\Files\RNN\imdb_rating_prediction\imdb_rating_prediction.py.py" 
A localhost appears in your default web browser and finally you are about to predict the IMDB Rating on the basis of your own description (short story/ abstract) of a movie/ web-series.
